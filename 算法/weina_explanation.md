# 维纳滤波与约束最小二乘方滤波 — 代码详解与对比

## 概述

本程序实现了两种经典的频域图像复原算法：

| 算法 | 英文名 | 准则 |
|------|------|------|
| 维纳滤波 | Wiener Filter | **最小均方误差（MMSE）** |
| 约束最小二乘方滤波 | Constrained Least Squares Filter | **平滑约束下的最小二乘** |

两者都用于从被模糊和噪声污染的图像中恢复原始图像，但设计思路和参数选择方式不同。

---

## 图像退化模型

两种滤波共用同一个退化模型：

```
g(x,y) = f(x,y) ⊗ h(x,y) + n(x,y)

频域: G(u,v) = F(u,v) × H(u,v) + N(u,v)
```

| 符号 | 含义 |
|------|------|
| `f` | 原始清晰图像 |
| `h` | 退化函数（点扩散函数 PSF） |
| `n` | 加性高斯噪声 |
| `g` | 观测到的退化图像 |
| `F, H, N, G` | 各自在频域的傅里叶变换 |

本程序使用的大气湍流退化函数：

```
h(x,y) = exp(−√(x²+y²) / scale)
```

这是一个径向对称的指数衰减函数，模拟光线穿过湍流大气层时的散射效应。

## 完整代码逐函数解释

### 1. `build_H(h, w)` — 构建退化函数（第 7-21 行）

```python
def build_H(h, w):
    yy, xx = np.meshgrid(np.arange(h), np.arange(w), indexing='ij')
    yy = yy.astype(np.float32) - h // 2
    xx = xx.astype(np.float32) - w // 2
    dist = np.sqrt(xx**2 + yy**2)
    h = np.exp(-dist / 10.0)
    h = h / np.sum(h)
    H = np.fft.fft2(np.fft.ifftshift(h))
    return H
```

| 行号 | 代码 | 解释 |
|------|------|------|
| 9-10 | `np.meshgrid(..., indexing='ij')` | 创建以 `(0,0)` 为左上角的坐标网格。`indexing='ij'` 让第一个维度沿行变化、第二个沿列变化，与图像的 (h, w) 结构一致。 |
| 11-12 | `yy = yy - h//2`, `xx = xx - w//2` | 将坐标原点从左上角平移到图像中心。中心处 `(0,0)` 距离为 0，PSF 值最大。 |
| 15 | `dist = np.sqrt(xx**2 + yy**2)` | 计算每个像素到中心的欧氏距离 `r = √(x²+y²)`。 |
| 16 | `h = np.exp(-dist / 10.0)` | **大气湍流退化函数**。`scale=10` 控制衰减速度——越小衰减越快，模糊越轻微；越大衰减越慢，模糊越严重。 |
| 17 | `h = h / np.sum(h)` | 归一化，使 PSF 的总能量为 1（保证退化后图像总亮度不变）。 |
| 19 | `np.fft.ifftshift(h)` | **关键操作**：将原点从图像中心移到四角。因为 `fft2` 默认原点在 `[0,0]`（左上角），而我们的 PSF 以中心为原点，必须先 `ifftshift` 才能对齐。 |
| 19 | `np.fft.fft2(...)` | 对移位后的 PSF 做二维 FFT，得到**光学传递函数 H(u,v)**（OTF），这是复数数组。 |

> **为什么不直接在频域定义 H？** 因为在空域定义 PSF 更直观——`exp(-r/10)` 描述了光在空间中的扩散模式。FFT 后自动得到对应的频域表示。

### 2. `build_g(image, H, noise)` — 退化图像生成（第 24-34 行）

```python
def build_g(image, H, noise=5):
    h, w = np.shape(image)
    F = np.fft.fft2(image.astype(np.float32))
    FH = np.real(np.fft.ifft2(F * H))        # 频域相乘 = 空域卷积
    noise = np.random.normal(0, noise, (h, w)).astype(np.float32)
    g = FH + noise
    g = np.clip(g, 0, 255).astype(np.uint8)
    return g
```

| 行号 | 代码 | 解释 |
|------|------|------|
| 28 | `F = np.fft.fft2(...)` | 对原图做二维 FFT，得到频谱 `F(u,v)`。 |
| 29 | `F * H` | **卷积定理**：空间域的卷积 = 频率域的逐元素相乘。`F×H` 在频域完成模糊操作，比空间域双重循环快得多。 |
| 29 | `np.fft.ifft2(F * H)` | 逆 FFT 回到空间域，得到模糊后的图像。 |
| 29 | `np.real(...)` | 取实部。理论上模糊图像是纯实数的，因浮点精度可能有微小虚部残留。 |
| 30 | `np.random.normal(0, noise, ...)` | 生成均值为 0、标准差为 `noise` 的高斯白噪声。 |
| 31 | `g = FH + noise` | 退化图像 = 模糊图像 + 噪声。 |
| 32 | `np.clip(g, 0, 255)` | 截断到 [0, 255]，防止越界。 |

### 3. `weina(image, K)` — 维纳滤波（第 37-52 行）

```python
def weina(image, K=0.01):
    h, w = np.shape(image)
    H = build_H(h, w)
    g = build_g(image, H)

    G = np.fft.fft2(g.astype(np.float32))
    H_conj = np.conj(H)
    F_pre = G * H_conj / (np.abs(H)**2 + K)

    f_pre = np.real(np.fft.ifft2(F_pre))
    f_pre = np.clip(f_pre, 0, 255).astype(np.uint8)
    return g, f_pre
```

**核心公式：**

```
F̂(u,v) = G(u,v) × H*(u,v) / (|H(u,v)|² + K)
```

| 行号 | 代码 | 解释 |
|------|------|------|
| 42 | `H = build_H(h, w)` | 构造退化函数 H（与生成退化图时的是同一个 H）。 |
| 43 | `g = build_g(image, H)` | 用 H 退化原图，得到 `g`。实际应用中 `g` 是给定的观测数据，这里为了演示而模拟。 |
| 46 | `G = np.fft.fft2(g)` | 对退化图做 FFT，得到 `G(u,v)`。 |
| 47 | `H_conj = np.conj(H)` | 求 H 的共轭 `H*`。共轭的作用是**逆转相位失真**——H 引入的相位偏移被 H* 抵消。 |
| 48 | `np.abs(H)**2` | `|H|²` 即 H 的功率谱，表示退化函数在每个频率上对信号的衰减程度。 |
| 48 | `/ (|H|² + K)` | **K 是维纳滤波的关键**。它防止 `|H|² ≈ 0` 时除零爆炸（逆滤波的病态问题）。K 相当于噪声-信号功率比的先验估计。 |

**K 参数的三种行为：**

| K 值 | 行为 | 视觉效果 |
|------|------|------|
| K → 0 | 退化为逆滤波 `G/H` | 噪声被无限放大，图像出现严重振铃 |
| K 适中 | 在去模糊与抑噪间平衡 | **最佳复原效果** |
| K → ∞ | `F̂ → 0` | 纯黑，无意义 |

### 4. `min_ercheng(image, r)` — 约束最小二乘方滤波（第 55-82 行）

```python
def min_ercheng(image, r=0.01):
    h, w = np.shape(image)
    H = build_H(h, w)
    g = build_g(image, H)

    # 构建拉普拉斯算子
    l = np.zeros((h, w), dtype=np.float32)
    l[0, 0] = -4.0    # 中心
    l[0, 1] = 1.0     # 右邻
    l[0, w-1] = 1.0   # 左邻（环绕）
    l[1, 0] = 1.0     # 下邻
    l[h-1, 0] = 1.0   # 上邻（环绕）
    L = np.fft.fft2(np.fft.ifftshift(l))

    G = np.fft.fft2(g.astype(np.float32))
    H_conj = np.conj(H)
    F_pre = G * H_conj / (np.abs(H)**2 + r * np.abs(L)**2)

    f_pre = np.real(np.fft.ifft2(F_pre))
    f_pre = np.clip(f_pre, 0, 255).astype(np.uint8)
    return g, f_pre
```

**核心公式：**

```
F̂(u,v) = G(u,v) × H*(u,v) / (|H(u,v)|² + r × |L(u,v)|²)
```

**拉普拉斯算子的构建（第 64-72 行）：**

| 行号 | 代码 | 解释 |
|------|------|------|
| 64 | `l = np.zeros((h, w))` | 创建与图像同尺寸的全零数组，作为待填充的拉普拉斯核。 |
| 66 | `l[0,0] = -4.0` | 中心权重（位于 `[0,0]`，`ifftshift` 后会移到图像中心）。 |
| 67-70 | `l[0,1]=1, l[0,w-1]=1, ...` | 四个邻居分别加权 +1。使用环绕索引（`w-1`, `h-1`）使得核在 `ifftshift` 后正确排列为标准的十字形：`[[0,1,0],[1,-4,1],[0,1,0]]`。 |
| 72 | `L = np.fft.fft2(np.fft.ifftshift(l))` | 同 H 的构造方式：先 `ifftshift` 移中心到四角，再 FFT 得到频域拉普拉斯算子 `L(u,v)`。 |

**为什么用拉普拉斯算子？**

拉普拉斯是二阶微分算子，天然是一个**高通滤波器**——它在平坦区输出为零，在边缘和噪声区输出大值。因此 `|L(u,v)|²` 在低频处 ≈ 0（允许通过），在高频处很大（施加惩罚），实现了**频率自适应的正则化**。

**r 参数的三种行为：**

| r 值 | 行为 | 视觉效果 |
|------|------|------|
| r → 0 | 退化为逆滤波 | 噪声放大，但与维纳不同——因为没有 K 的均匀压制 |
| r 适中 | 高频噪声被平滑，低频保持 | **在平滑噪声的同时较好地保留边缘** |
| r → ∞ | 过度平滑 | 图像趋于模糊，细节丢失 |

## 维纳滤波 vs. 约束最小二乘方滤波 核心对比

### 公式对比

```
维纳:     F̂ = G × H* / (|H|² + K)           ← K 是常数
CLS:      F̂ = G × H* / (|H|² + r × |L|²)    ← r × |L|² 随频率变化
```

唯一的区别在分母的正则化项：维纳用**常数 K**，CLS 用**频率自适应的 r|L|²**。

### 正则化行为对比

```
频率 →
 低频                            高频
  |                               |
  | 维纳: -----K-----              |  常数压制，所有频率一视同仁
  |  CLS:    \         /|L|²       |  低频松、高频紧，差异化处理
  |           \      /
  |            \   /
  |             \/
```

| 维度 | 维纳滤波 | 约束最小二乘方滤波 |
|------|------|------|
| **优化准则** | 最小化均方误差 E[\|f − f̂\|²] | 最小化 ‖g − Hf̂‖²，约束 ‖Lf̂‖² ≤ C |
| **正则化项** | 常数 K（噪声信号功率比） | r × \|L(u,v)\|²（频率自适应） |
| **是否需要噪声信息** | 需要知道噪声功率谱（K = Pn/Pf） | **不需要**，r 是纯数值参数 |
| **频率选择性** | 无——所有频率追加相同的 K | **有**——高频惩罚大、低频惩罚小 |
| **边缘保持** | 一般，K 调大后整个图像都平滑 | **较好**，低频（边缘的主要成分）被保护 |
| **参数调优难度** | 需要估计噪声-信号比 | r 可通过迭代算法自动确定（本代码手动指定） |
| **振铃效应** | 容易出现（逆滤波残留） | 相对较少 |
| **计算复杂度** | 较低（一次除法） | 略高（多算一个 \|L\|²） |

### 参数选择指南

| 场景 | 推荐算法 | 推荐参数 |
|------|------|------|
| 噪声水平已知 | 维纳滤波 | K ≈ 噪声方差 / 信号方差 |
| 噪声水平未知 | 约束最小二乘方滤波 | r = 0.001~0.1，视觉效果调优 |
| 需要保留锐利边缘 | CLS | r 偏小（0.0001~0.001） |
| 强噪声场景 | 维纳滤波 | K 偏大（0.1~1.0） |
| 仅轻度退化 | 两者皆可 | K 或 r 都选偏小值 |

## 理论补充：为什么它们都是"最优"的？

- **维纳滤波**是**统计最优**的——如果知道信号和噪声的功率谱，它就是所有线性滤波器中均方误差最小的。
- **约束最小二乘方滤波**是**确定性最优**的——它在"平滑度"约束下最小化数据拟合误差，不依赖随机过程的假设。

两者在数学上有深刻联系：当正则化参数满足 `r = K / λ`（λ 是拉格朗日乘子）时，两种滤波产生**完全相同的输出**。但在实际使用中，由于参数选取方式不同（K 来自功率谱估计，r 来自视觉或迭代优化），结果通常不同。
