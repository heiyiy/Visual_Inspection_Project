# Sobel 算子图像增强 — 逐行代码详解

## 概述

Sobel 算子是一种**基于一阶微分的图像边缘检测算子**。它通过两个 3×3 的卷积核分别计算图像在水平方向（x）和垂直方向（y）上的梯度，然后将两个方向的梯度合成，得到边缘强度图。边缘处像素值变化剧烈，梯度大，因此 Sobel 算子的输出在边缘位置较亮，平坦区域较暗，从而实现图像增强。

### 第 12-14 行：水平方向卷积核 Gx

```python
    Gx = np.array([[-1, 0, 1],
                   [-2, 0, 2],
                   [-1, 0, 1]])
```

这是 Sobel **水平方向**的 3×3 卷积核。它的特点是：

- **左列全是负数，右列全是正数**，中间列为 0。
- 这意味着对于当前像素，用**右边像素减左边像素**来近似水平方向的导数（即 x 方向的变化率）。
- 中间行权重为 ±2，给靠近中心的行更高的权重，增强对当前行边缘的响应。
- **用途**：检测**垂直走向**的边缘（因为垂直边缘意味着水平方向上有剧烈变化）。

---

### 第 17-19 行：垂直方向卷积核 Gy

```python
    Gy = np.array([[-1, -2, -1],
                   [0,  0,  0],
                   [1,  2,  1]])
```

这是 Sobel **垂直方向**的 3×3 卷积核。它的特点是：

- **上行全是负数，下行全是正数**，中间行为 0。
- 用**下边像素减上边像素**来近似垂直方向的导数（即 y 方向的变化率）。
- 中间列权重为 ±2，给靠近中心的列更高的权重。
- **用途**：检测**水平走向**的边缘（因为水平边缘意味着垂直方向上有剧烈变化）。

### 第 22-23 行：边界填充

```python
    pad = 1
    padded = np.pad(image, pad, mode='edge')
```

| 行号 | 代码片段 | 解释 |
|------|----------|------|
| 22 | `pad = 1` | 核大小为 3×3，需要在四周各填充 1 个像素（`3 // 2 = 1`），这样才能让原图边缘的像素也有完整的 3×3 邻域可用。 |
| 23 | `padded = np.pad(image, pad, mode='edge')` | 调用 `np.pad` 对图像边界进行填充。`mode='edge'` 表示用图像最外层的像素值来填充——比如左上角缺少的像素就直接复制左上角那个像素的值。这是最常用也最简单的边界处理方式。填充后图像尺寸从 `(h, w)` 变为 `(h+2, w+2)`。 |

### 第 25-27 行：准备输出数组

```python
    h, w = np.shape(image)
    result_x = np.zeros((h, w), dtype=np.float32)
    result_y = np.zeros((h, w), dtype=np.float32)
```

| 行号 | 代码 | 解释 |
|------|------|------|
| 25 | `h, w = np.shape(image)` | 获取原图的高度 `h` 和宽度 `w`。注意是取**原图**的尺寸（不含填充），因为我们输出的结果应该和输入一样大。 |
| 26 | `result_x = np.zeros((h, w), dtype=np.float32)` | 创建一个 `h×w` 的全零数组，用来存放每个像素的**水平梯度值**。使用 `float32` 是因为梯度可能是负数或小数，`uint8` 装不下。 |
| 27 | `result_y = np.zeros((h, w), dtype=np.float32)` | 同理，存放每个像素的**垂直梯度值**。 |

---

### 第 30-35 行：核心卷积循环

```python
    for i in range(h):
        for j in range(w):
            window = padded[i:i+3, j:j+3]
            result_x[i, j] = np.sum(window * Gx)
            result_y[i, j] = np.sum(window * Gy)
```

这是整段代码的**核心**，逐行解释：

| 行号 | 代码 | 解释 |
|------|------|------|
| 30 | `for i in range(h):` | 外层循环，遍历图像的每一**行**（从上到下）。 |
| 31 | `for j in range(w):` | 内层循环，遍历当前行的每一**列**（从左到右）。`(i, j)` 就是当前正在处理的像素坐标。 |
| 32 | `window = padded[i:i+3, j:j+3]` | 从填充后的图像中切出以 `(i, j)` 为中心的 **3×3 邻域**。例如当 `i=5, j=10` 时，取出 `padded` 的第 5~7 行、第 10~12 列这 9 个像素。 |
| 33 | `result_x[i, j] = np.sum(window * Gx)` | **卷积操作**：将 3×3 邻域与 Gx 核**逐元素相乘**（`window * Gx`），然后用 `np.sum()` 把 9 个乘积加起来。这个和就是该像素的水平梯度值。正值表示从左到右变亮，负值表示从右到左变亮。 |
| 34 | `result_y[i, j] = np.sum(window * Gy)` | 同理，用 Gy 核计算垂直梯度。正值表示从上到下变亮，负值表示从下到上变亮。 |

> **卷积的直观理解**：把 3×3 窗口里的 9 个像素分别乘以卷积核对应位置的 9 个权重，然后求和。这个和反映了该局部区域的梯度方向和强度。

---

### 第 37 行：计算梯度幅值

```python
    gradient = np.sqrt(result_x ** 2 + result_y ** 2)
```

这行做了三件事：

1. `result_x ** 2`：将水平梯度数组的每个元素**平方**（消除正负号的影响，因为边缘强度只关心变化有多"大"，不关心方向的正负）。
2. `result_y ** 2`：同理，垂直梯度平方。
3. `np.sqrt(...)`：对平方和**开方**，得到最终的梯度幅值（欧几里德范数）。

公式：**G = √(Gx² + Gy²)**

开方后的 `gradient` 仍然是 `float32` 类型，数值范围不定（取决于图像内容）。

---

### 第 39-40 行：归一化到 0-255

```python
    gradient = gradient / gradient.max() * 255
    gradient = gradient.astype(np.uint8)
```

| 行号 | 代码 | 解释 |
|------|------|------|
| 39 | `gradient = gradient / gradient.max() * 255` | **线性归一化**。先用 `gradient.max()` 找到梯度图中的最大值，然后把所有值除以这个最大值——这样数据被缩放到 `[0, 1]` 区间。再乘以 255，缩放到 `[0, 255]` 区间，方便作为灰度图像显示。 |
| 40 | `gradient = gradient.astype(np.uint8)` | 将数据类型从 `float32` 转为 `uint8`（0~255 的无符号整数），这是标准灰度图的存储格式。 |

## Sobel 算子原理小结

```
原始图像 3×3 邻域示例:
┌─────┬─────┬─────┐
│  50 │  55 │  60 │    左边暗，右边亮 → 水平梯度为正值
├─────┼─────┼─────┤
│  48 │  53 │  58 │    （存在垂直边缘）
├─────┼─────┼─────┤
│  45 │  50 │  55 │
└─────┴─────┴─────┘

Gx = (-1)×50 + 0×55 + 1×60 + (-2)×48 + 0×53 + 2×58 + (-1)×45 + 0×50 + 1×55
   = -50 + 0 + 60 - 96 + 0 + 116 - 45 + 0 + 55
   = 40  ← 正数，表示从左到右像素变亮

Gy = (-1)×50 + (-2)×55 + (-1)×60 + 0×48 + 0×53 + 0×58 + 1×45 + 2×50 + 1×55
   = -50 - 110 - 60 + 0 + 0 + 0 + 45 + 100 + 55
   = -20  ← 负数，表示从上到下像素变暗

梯度幅值 = √(40² + (-20)²) = √(1600 + 400) = √2000 ≈ 44.7
```

Sobel 算子的本质就是**用差分近似微分**，从而找到像素值变化最剧烈的地方——也就是边缘所在。
